= Supported platforms

`inara-runtime` is a Kotlin Multiplatform library.
It targets:

[cols="1,3"]
|===
| Platform | Targets

| JVM
| `jvm`

| iOS
| `iosArm64`, `iosSimulatorArm64`, `iosX64`

| watchOS
| `watchosArm32`, `watchosArm64`, `watchosDeviceArm64`, `watchosSimulatorArm64`

| tvOS
| `tvosArm64`, `tvosSimulatorArm64`

| macOS
| `macosArm64`

| Android Native
| `androidNativeArm32`, `androidNativeArm64`, `androidNativeX64`, `androidNativeX86`

| Linux
| `linuxX64`, `linuxArm64`

| Windows
| `mingwX64`

| JS
| browser, Node.js

| Wasm/JS
| browser, Node.js
|===

Android applications use the JVM artifact.

Inara behaves exactly the same on every platform.
The only exception is JS and Wasm, where xref:thread-safety.adoc[thread synchronization] is a no-op, since there is no thread to synchronize.

NOTE: `macosX64`, Intel macOS, is deliberately not a target: Kotlin deprecated it in 2.3.20 and will remove it.
`iosX64`, the Intel iOS _simulator_, is kept because Kotlin still supports it.
